## 2. Sequence Synchronization Check

```sql
SELECT c.relname AS sequence_name,
       t.relname AS table_name,
       a.attname AS column_name,
       pg_sequence_last_value(c.oid::regclass) AS current_seq_val,
       (xpath('/row/max/text()', xml_val))[1]::text::bigint AS max_table_id
FROM pg_class c
JOIN pg_depend d ON d.objid = c.oid AND d.deptype = 'a'
JOIN pg_class t ON t.oid = d.refobjid
JOIN pg_attribute a ON a.attrelid = t.oid AND a.attnum = d.refobjsubid
CROSS JOIN LATERAL (
    SELECT query_to_xml(format('SELECT MAX(%I) as max FROM public.%I', a.attname, t.relname), false, true, '') as xml_val
) x
WHERE c.relkind = 'S' AND t.relnamespace = 'public'::regnamespace;
```
*Output Summary:* All 6 identity sequences (`*_id_seq`) are aligned with or exceed the corresponding `MAX(id)` values in the table data, verifying that new record insertions will not encounter primary key collisions (`SQLSTATE 23505`).
