7. Prevention, Contributions & Declarations

7.1 Practical DBA Preventive Recommendations

  1. Automated Privilege Linting in CI/CD: Mandate automated schema migration checks in GitHub Actions that fail pull requests if whole-table UPDATE or DELETE grants are issued on authentication catalogs (app_user, admins).
  2. Mandatory Soft-Deletion on Compliance Entities: Establish an institutional DBA standard prohibiting CASCADE delete rules on historical audit, financial, or compliance tables. Enforce soft deletion (is_deleted, deleted_at) across all operational entities.
  3. Engine-Level State Audit Triggers: Mandate that all state transition tables be driven by PostgreSQL AFTER UPDATE triggers rather than client application code, ensuring complete auditability for direct SQL updates and batch jobs.
  4. Automated 3-2-1 Disaster Drills: Pair database-level logical backups (pg_dump -Fc) with cluster-wide role archiving (pg_dumpall --globals-only) and schedule monthly automated restore drills into disposable test environments.
